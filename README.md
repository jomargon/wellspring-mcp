# Wellspring for Withings

**Unofficial integration for Withings devices.** Not affiliated with, endorsed
by, or supported by Withings. Withings is a trademark of its respective owner.

A remote [MCP](https://modelcontextprotocol.io) server that lets you ask Claude
about your own Withings health data — sleep, body measurements, activity, and
heart — in plain language. Read-only. Each user authorizes their own Withings
account. No health data is ever stored server-side; only OAuth tokens are
retained, encrypted at rest.

> 🚧 **Under development.** Not yet accepting connections. This README will
> grow a user quickstart, privacy summary, and self-hosting guide as the
> project reaches each milestone (spec: `PLAN.md` §9.6).
